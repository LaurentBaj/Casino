# Casino.Core

<hr>

This is a game library for the card game Casino. It is comprised of functions that handles player actions and game state. Its goal is to be total frontend agnostic and should aid the developer with
creating the revered game with great ease and correctness.


### Events and handling

1. Game initialization ✔️
2. Player Actions
   - Deal cards ✔️
   - Collect ✔️ 
   - Merge / Build
3. Summarize game -> Provide game details (winner, points etc..)
